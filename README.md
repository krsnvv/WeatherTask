# WeatherTask

Консольная программа на Python для получения текущей погоды по списку городов через API `wttr.in`.

Программа читает список городов из файла, получает для каждого города текущую температуру и страну, выводит информацию по каждому городу, а затем группирует результаты по странам и рассчитывает статистику.

## Что делает программа

После запуска программа:

- загружает список городов из файла `cities.txt`;
- для каждого города делает запрос к `wttr.in`;
- получает текущую температуру в градусах Цельсия;
- определяет страну;
- сохраняет данные в модель `WeatherData`;
- выводит информацию по каждому городу;
- группирует города по странам;
- рассчитывает для каждой страны:
  - количество городов;
  - среднюю температуру;
  - минимальную температуру;
  - максимальную температуру.

## Структура проекта

```text
WeatherTask/
├── main.py
├── cities.txt
└── README.md
```

`main.py` — основной код программы.

`cities.txt` — список городов, для которых необходимо получить погоду.

## Список городов

В текущем варианте используется список:

```text
Moscow
Khabarovsk
Saint-Petersburg
Vienna
Izhevsk
Perm
NhaTrang
Villach
```

При необходимости список можно изменить. Каждый город должен находиться на отдельной строке.

## Требования

Для запуска нужен:

- Python 3.10 или новее;
- доступ в интернет.

Дополнительные библиотеки устанавливать не требуется.

Используются только стандартные модули Python:

```text
json
urllib
dataclasses
collections
```

## Используемый API

Для получения данных используется:

```text
https://wttr.in/{City}?format=j1
```

Например:

```text
https://wttr.in/Moscow?format=j1
```

Ответ API приходит в формате JSON.

Из ответа используются:

- `current_condition[0].temp_C` — текущая температура;
- `nearest_area[0].country[0].value` — страна.

## Модель данных

Для хранения информации используется класс `WeatherData`:

```python
@dataclass
class WeatherData:
    city: str
    temperature: int
    country: str
```

Он содержит:

- название города;
- текущую температуру;
- страну.

## Запуск

Открыть терминал в папке проекта и выполнить:

```powershell
python main.py
```

Программа сама прочитает файл `cities.txt` и начнёт получать данные.

## Обработка ошибок

Если для какого-либо города не удалось получить данные, программа выводит сообщение об ошибке и продолжает работу с остальными городами.

Это позволяет не прерывать выполнение всего задания из-за ошибки одного запроса.
